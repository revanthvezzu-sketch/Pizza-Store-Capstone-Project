<h1>Pizza Store Capstone Project<h1>

<h2>Features</h2>

<p>
  <i>In workflow-</i> 
  1. User login/register<br>
  2. User Order the item<br>
  3. User Item store in card<br>
  4. User place order<br>
  5. User's Order store in admin, admin will edit item<br>
  6. Admin will approve/deny the order<br>
  7. Admin approve/deny, bill will genrated<br>
  8. Admin can change status of the order(Ready, Deliverd, cancalled)<br>
  9. Bill will be popup in both admin and user<br>
  10. Bill will be stored in user and admin<br>
